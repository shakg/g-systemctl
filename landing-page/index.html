NEWLive graphs and a Docker containers tab

Every service.
One terminal.

A keyboard-driven TUI for systemd, launchd and Docker. Filter, inspect, graph, restart and follow logs — without typing a unit name twice.

Install View source C++17 · MIT
~ — sudo g-systemctl
No agent, no daemon. It runs the commands you would.

Navigation

Enter goes down.
Esc comes back.

  1. 01

    List

    Every unit or container with status, PID, CPU and memory. Type anywhere to filter.

  2. 02

    Detail page

    Summary, live graphs and a short log strip. Actions target the item shown.

  3. 03

    Full-size logs

    The strip expands to the whole screen. PgUp / PgDn to scroll.

Features

What you reach for,
one key away.

postgresql.service · graphs every 2s

Live graphs on the detail page

CPU, memory, tasks and IO, sampled every 2 seconds with 10 minutes of history. Beside the summary at 100+ columns; Alt+g swaps them in on narrow terminals.

Filter: ▏

    Filter as you type

    No search mode. Start typing; the list narrows. -f nginx starts filtered.

    ●one long line

    Commands you can read

    Long ExecStart lines and Docker entrypoints are split one option per line. The script of sh -c is indented one level deeper.

    api · docker logs -f

    Logs that keep following

    journalctl -f for services, docker logs -f for containers. Reattaches after a restart or a recreate with the same name.

    Resources api
    CPUs1.00
    Memory1g
    PIDs200
    Restartunless-stopped

    Limits, changed in place

    Alt+u edits CPUs, memory, swap, PIDs and restart policy with docker update. No recreate.

    api · environment
    Altshidden

    Secrets stay masked

    Env values whose names look secret — PASSWORD, TOKEN, KEY — are hidden until you press Alt+s.
