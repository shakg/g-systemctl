    Features
    
        
    Stop typing unit names. Start seeing them.
    
        
    Everything you reach for systemctl, journalctl and
          launchctl to do, on one keyboard-driven screen.
    

        
    
          
    
            
    
              
    Filter:8/8 services
    
              
    
            
    
            
    Type to filter
    
            
    Start typing and the list narrows as you go. No prompt to open, no flags to remember. Pass
              -f nginx to start already filtered.
    
          
    

          
    
            
    
              
    cron.service● active
    
              
    nginx.service● active○ inactive
    
              
    redis.service● active
    
              ⏎
            
    
            
    One key to start or stop
    
            
    Enter toggles. Alt+R restarts. PID, CPU and memory update in place.
    
          
    

          
    
            
    
              
    
                
    
              
    
            
    
            
    Live logs, right there
    
            
    Alt+L streams journalctl for the selected unit in a split pane.
              Page through history with PgUp, close with Alt+C.
    
          
    

          
    
            
    
              
    1[Service]
    
              
    2ExecStart=/usr/sbin/nginx
    
              
    3Restart=always
    
              
    4RestartSec=5
    
              
    :wq
    
            
    
            
    Edit unit files
    
            
    Alt+E opens the unit in your editor. Save, and the daemon reloads for you.

    Install
    
        
    Up and running in a minute.
    
        
    Prebuilt for Linux x86_64 and macOS. Or build it from source in one CMake run.
        
    

        
    
          
    
            
            
            
            
            
          
    

          
    
            
    
              
    
                
    Ubuntu 22.04+ · Debian 12+
    
                
    $ curl -LO https://github.com/shakg/g-systemctl/releases/latest/download/g-systemctl-linux-amd64.deb
$ sudo apt install ./g-systemctl-linux-amd64.deb
    
              
    
            
    

            
    
              
    
                
    Homebrew
    
                
    # Download the formula from the latest release
$ curl -LO https://github.com/shakg/g-systemctl/releases/latest/download/g-systemctl.rb
$ brew install ./g-systemctl.rb
    
              
    
            
    

            
    
              
    
                
    x86_64 tarball
    
                
    $ curl -LO https://github.com/shakg/g-systemctl/releases/latest/download/g-systemctl-linux-x86_64.tar.gz
$ tar -xzf g-systemctl-linux-x86_64.tar.gz
$ sudo install -m 755 g-systemctl-*/g-systemctl /usr/local/bin/g-systemctl
    
              
    
              
    Statically links libstdc++, so it only needs glibc 2.34 or newer (Ubuntu 22.04+, Debian
                12+, Fedora 35+ and similar).
    
            
    

            
    
              
    
                
    Linux and macOS
    
                
    # Needs git, CMake 3.14+ and GCC 7+ / Clang 5+ (Xcode CLT on macOS)
$ git clone https://github.com/shakg/g-systemctl.git
$ cd g-systemctl
$ cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
$ cmake --build build --parallel
$ sudo cmake --install build
    
              
    
            
    

            
    
              
    
                
    Run next to the downloaded file
    
                
    $ curl -LO https://github.com/shakg/g-systemctl/releases/latest/download/SHA256SUMS.txt
$ sha256sum --ignore-missing -c SHA256SUMS.txt
    
              
    
              
    On macOS use shasum -a 256 --ignore-missing -c SHA256SUMS.txt.
