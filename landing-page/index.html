g-systemctl(1)

A terminal UI for systemd and launchd services. List, filter, start, stop and restart them, read their journal and edit their unit files from one screen.

Install Source on GitHub

SYNOPSIS

g-systemctl [--system | --user] [-f text]

user@prod-01: ~ click to type

A simulation that runs in your browser, with made-up services. Press Esc to get a shell and try the options below.

KEYS

Click a row to send that key.

DESCRIPTION

g-systemctl shows the services that systemctl list-units reports, one per row, with their state, PID, CPU and memory. On macOS it shows the jobs from launchctl list. Typing filters the list by name.

Enter starts a stopped unit and stops a running one. Alt+R restarts it. When an action needs root and you did not start the program with sudo, it asks for your password in a small dialog and runs the command with sudo.

Alt+L runs journalctl -u unit -f -n 100 and shows the output under the list until you press Alt+C. Alt+E runs systemctl edit --full on the unit, which reloads it when you save. Alt+Shift+R runs systemctl daemon-reload.

Log streaming, unit editing and daemon-reload are Linux only. The mouse works too: click a row to select it, scroll to move, click Reload or Shortcuts in the top bar.

OPTIONS

--system
Show system services. This is the default.
--user
Show the services of your user session, as systemctl --user does. No password is needed.
-f, --filter text
Start with text already typed into the filter.
-v, --version
Print the version and platform, then exit.
-h, --help
Print usage, then exit.

Run sudo g-systemctl to start and stop system services without the password dialog.

ENVIRONMENT

GSYSTEMCTL_EDITOR
Editor used by Alt+E. Defaults to vim.

INSTALL

$ curl -LO https://github.com/shakg/g-systemctl/releases/latest/download/g-systemctl-linux-amd64.deb
$ sudo apt install ./g-systemctl-linux-amd64.deb

For amd64 on Ubuntu 22.04 or later and Debian 12 or later.

$ curl -LO https://github.com/shakg/g-systemctl/releases/latest/download/g-systemctl.rb
$ brew install ./g-systemctl.rb

The formula builds from the tagged source, so Homebrew installs CMake first if you don't have it.

$ curl -LO https://github.com/shakg/g-systemctl/releases/latest/download/g-systemctl-linux-x86_64.tar.gz
$ tar -xzf g-systemctl-linux-x86_64.tar.gz
$ sudo install -m 755 g-systemctl-*/g-systemctl /usr/local/bin/g-systemctl

One x86_64 binary that needs glibc 2.34 or later: Ubuntu 22.04, Debian 12, Fedora 35 and newer. Checksums are in SHA256SUMS.txt on each release.

# Needs git, CMake 3.14+ and a C++17 compiler
$ git clone https://github.com/shakg/g-systemctl.git
$ cd g-systemctl
$ cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
$ cmake --build build --parallel
$ sudo cmake --install build
